CCNA 1: Introduction to Networks - Cisco Networking Academy

This repository contains practical activities, Packet Tracer (.pka) labs, documentation (.pdf), and calculation models (.xlsx) completed as part of the Cisco Certified Network Associate (CCNA 1 v7) curriculum.

Repository Author

Author: Isabela Henao García

Course: CCNA 1 - Cisco Networking Academy

Contents Overview

The repository is organized by module topics covering essential networking concepts, subnetting, IPv6 configuration, network device security, and network troubleshooting.

File Types Included

.pka: Cisco Packet Tracer activity files containing completed network topologies and configurations.

.pdf: Lab instructions, answered guides, and evaluation reports.

.xlsx: Subnetting tables and VLSM design spreadsheets.

Software Requirements

To open and inspect the simulation files in this repository, you will need:

Cisco Packet Tracer (v8.0 or later recommended)

A PDF reader (e.g., Adobe Acrobat, web browser)

Microsoft Excel or compatible spreadsheet software (for .xlsx files)

How to Use

Clone the repository:

git clone https://github.com/IsabelaHenaoGarcia/CCNA-1--ACADEMIA-DE-REDES-DE-CISCO.git


Open any .pka file directly inside Cisco Packet Tracer to view the network topology and active configurations.

Refer to the corresponding .pdf files for step-by-step documentation and answered lab questions.
